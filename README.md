## 🚀 Deployment on Vercel

### Prerequisites
- GitHub account
- Vercel account

### Steps to Deploy

1. **Repository already exists** on GitHub

2. **Connect to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Select this GitHub repository
   - Click "Deploy"

3. **Access Your Portfolio**
   - Your portfolio will be live at: `https://lwazi-siyanda-sibiya.vercel.app`
